《明日方舟：终末地》战斗系统拆解

Harry · 2026

《明日方舟：终末地》是由鹰角网络开发的一款二次元 3D RPG 游戏，该作延续了《明日方舟》的世界观，玩家扮演终末地工业的管理员，率领干员们保卫、推展人类的边疆。

在游戏中，玩家以小队为单位进行探索、战斗，将角色编入最多四人的小队并操控其中一名角色进行操作。

本拆解案重点讨论终末地的战斗系统，这个战斗系统有着复杂的多乘区、元素效果、小队作战、特色技能等机制，但是通过对战技点和连携技 CD 的控制进行了极强的策略管理和节奏控制。本案将会通过拆解该战斗系统，剖析其繁杂内容和强管理是如何实现的，会带来什么优劣，以及如何基于这样的战斗系统对战斗体验进行改善。Mindmap 如下：

Mindmap：《终末地》战斗系统总览

1. 战斗系统的整体构成

《终末地》的战斗系统可以拆分为小队系统、职业系统、元素系统、攻击与技能系统、其他效果系统五个部分，实际上养成系统显然同样对战斗造成影响并且带来一定策略灵活性，但本案不进行讨论，结论处会给出原因。在乘区部分，角色的攻击、技能倍率 x 元素附着、爆发的倍率 x 其他效果的各自倍率=最终伤害；在策略部分，基础编队 x 考虑其他站场角色 x 角色的攻击回能 x 战技释放节奏 x 连携技触发和释放节奏 x 大招对轴 x 元素爆发对轴 x 其他效果对轴，构成了多角度的交叉策略结构。

可见五个系统互相交织，在乘区、策略上构建了一个复杂的总体战斗系统。

1.1 小队系统

《终末地》是以最多四人小队作为探索和战斗的单位，玩家在选择角色（干员）编队上场后，其操作的角色为"主控干员"。

但是与其他实际始终操作和切换单一角色（如《原神》）和其他角色会短暂同时在场（《绝区零》）不同，《终末地》的小队所有成员都是始终在场的，玩家可以直接释放其技能，不操作时小队中角色也会跟随主控干员进行普通攻击、闪避、追击等基础操作，战斗中小队内的其他干员在无法闪避时也会受到攻击。

图一：常见的作战中状态，四个干员都在提供攻击和效果

同时，战技点也是全队共用的，所以虽然无法完全直接操控四个干员，《终末地》的小队系统仍较大程度实现了单人操控的团队作战，不仅需要考虑主控角色的操作，同时也要兼顾队内的其他角色，尤其在有生存压力的状况下，小队中的角色战场是很容易死亡退场的，会对整体循环造成极大影响。

1.2 职业系统

《终末地》中的每位角色都有自身的职业，虽然不会对战斗操作本身产生影响，但是职业系统对干员在编队中扮演的角色产生影响，进而影响战斗编队的组成，导致整个循环策略的改变，所以此处单独作为一个系统进行拆解。

当前，干员的职业分为：

  • 近卫：擅长造成【破防】和【物理异常】，同时兼顾一定的伤害输出能力。
  • 术师：擅长造成【法术附着】和【法术异常】，同时兼具一定的伤害输出能力。
  • 突击：依靠其他干员的物理和法术效果，从而提供决定性的伤害输出能力。
  • 先锋：擅长回复技力，能帮助团队后续更好的释放技能。
  • 重装：拥有高生存能力，擅长保护和治疗队友，并对敌人发起反击。
  • 辅助：擅长以各类控制效果削弱敌人，也能为其他干员提供增益和支援。

干员职业会决定编队位置，以主流电属性队为例：

图二：经典电队

四个角色中，梨诺作为辅助负责提供各类效果和治疗，决和佩丽卡作为术士提供【法术附着】，庄方宜作为突击则消耗【法术附着】进行循环主攻。

角色职业区别形成了诸如此类的辅助位—附着位—主攻手的基本编队思路，在《终末地》的编队中是被广泛使用的。

1.3 元素系统

每位角色除自身职业外，还有自身的属性，目前《终末地》的属性共四个：物理、灼热、寒冷、电磁。由于相同属性之间才能产生较多配合，所以当前《终末地》的配队都以属性为基础。仍然以上文提到的电队为例，由于佩丽卡的战技、连携技都可以提供【电磁附着】，而决的战技可以将【电磁附着】扩散，庄方宜才能够通过反复消耗【电磁附着】进行循环输出。后文会对电队的输出循环进行整体拆解。

除了打上/消耗【法术附着】的编队逻辑外，还有直接进行【法术附着】叠加，产生【元素爆发】打出伤害的编队逻辑，如自然队。

可见元素系统也是《终末地》战斗系统底层逻辑的一环，是战斗策略和操作的核心之一。

1.4 攻击和技能系统

攻击和技能系统是《终末地》控制战斗节奏的核心，主要来源于三点：技力（释放战技所需的能量）全队共享且所有战技所需技力相同；连携技需要特殊条件触发、仅随时间回复；角色终结技需要战技和连携技命中回复。所以获取技力释放战技，触发连携技并等待下一轮循环（部分持续循环直到终结技充能完毕进入终结技中循环）就成为一种标准的作战节奏，后文通过实战进行分析。

1.5 其他效果系统

角色的技能还可以施加各种不同的效果，例如艾雅法拉连携技的"腐蚀"效果，可以减少敌人的所有抗性；许多辅助角色可以提供的"法术增幅"效果，可以提高对目标的法术伤害；决连携技的"囹圄"效果，减缓敌人行动等，同样作为伤害乘区或作战策略的额外内容，进一步复杂化了战斗。

2. 系统内容详解

2.1 基本战斗方式

角色通过普通攻击—重击循环进行基础攻击，普通攻击的最后一段为重击，可以回复技力并提升敌人失衡条。

图三：庄方宜的普通攻击介绍

角色可以闪避敌人攻击，会打断当前的动作，但是在普攻中进行单次或连续两次闪避不会打断普攻循环。

片段 1：闪避不会打断普攻循环

角色的重击、战技、连携技和部分直接造成伤害的终结技命中敌人，都会积攒敌人的失衡条。敌人失衡条攒满后进入一段时间失衡状态，不进行攻击，防御力下降，角色可以在此时打出一次处决攻击。

图四：庄方宜重击命中失衡条增加的瞬间

图五：庄方宜的处决攻击描述

2.2 战技

角色有各自特色的战技，技力储存产生战技点，战技点全队共享，战技点和技力在战斗状态下的屏幕下方居中显示，可以通过自然恢复、重击、和部分战技连携技的效果进行回复。

2.3 连携技

角色有各自特色的连携技，通过各自的条件触发，连携技的触发有冷却，该冷却仅随时间回复，连携技的状态条为：战斗界面左下角，角色头像下的白条。

2.4 终结技

角色有各自特色的终结技，通过战技、连携技效果进行回能，终结技状态：战斗画面右下角角色的战技键上方。

3. 实战循环拆解

本部分以电队（庄方宜、佩丽卡、梨诺、决（意形态））为例，通过整个实战循环拆解，意在表现在复杂的战斗系统下，通过战技、连携技控制战斗节奏，使得循环套路固定的情况。

电队在冷启动（2 技力点，全队 0 大招能量）状态下开始战斗时，以庄方宜终结技充能完毕的节点前后，分为充能进入终结技爆发的充能循环，和庄方宜终结技开启后的爆发循环两个循环部分。

图九：电队的双循环示意图，来源：B 站 up 血狼破军视频——《【终末地测评#12】能拐能奶！梨诺数据与实战测评》

由于充能循环机制更加复杂，展示充能循环后，爆发循环便不再赘述。

3.1 充能循环解析

充能循环由于庄方宜大招需要的能量和战技—连携技循环，分为两次相同的循环。

主控庄方宜进入战斗，梨诺开启战技进入演唱姿态，佩丽卡释放战技施加【电磁附着】，释放决连携技再次施加【电磁附着】，庄方宜持续普攻触发重击。

片段 2

触发重击后，先释放庄方宜连携技将两层【电磁附着】转换为两层【导电】状态，然后释放庄方宜战技消耗导电，生成 2 柄青霆剑，回复终结技能量，同时释放佩丽卡和梨诺连携技，再次施加【电磁附着】。

片段 3

待梨诺的连携技回转好以及战技点回复后，再次释放庄方宜战技消耗【电磁附着】，释放梨诺连携技。

片段 4

待决连携技回转好以及战技点回复后，重复一次循环即可充满庄方宜终结技，开启庄方宜终结技进入爆发循环。

3.2 循环小结

从循环中可以清晰的看出，战技、连携技的回复节奏和相互触发配合，以及终结技的充能，是有明显效果和数值设计意图的，即使不清楚具体技能效果，也可以机械的背轴进行循环。

可见，全系统的复杂度和实战中的简单循环产生了矛盾，这样的矛盾构成了战斗系统的优劣区间，接下来将分析这样的战斗系统所带来的影响，以及其优化空间。

4. 观点与优化方向

再次重申，经过以上拆解，清晰的展现了战斗系统全系统的复杂度和实战中的简单循环产生了矛盾，接下来尝试分析其原因、影响和优化方向。

4.1 矛盾原因：复杂性与可玩性设计与理解难度较大

带有战斗系统的 RPG 都会有共同的目标，即：对战斗进行创新以体现自家特色，但不能完全脱离市场习惯逻辑。在这样的目标下，对战斗系统的设计往往成为对有先例系统的改造拼装。

《终末地》选择了职业、元素、战技、连携的系统进行拼装，并且引入了全员站场的小队系统，这样在系统本身上就产生了较大的策略复杂度，这对于需要不断增加角色的持续性运营二游来说，策略设计和理解的难度是较大的。所以制作时果断舍弃了类似《原神》的元素反应，而是固定了单一的元素内部互动，仅有自然元素可以联系其他元素，从而固定了单一元素的编队策略；同时对角色职业进行区分，从而削弱了编队结构的策略复杂度。可见无论是考虑到玩家接受度还是设计难度，都导致了对系统引入后进行简单化的处理。

如此处理后显然带来的优势就是实现了既有特色，又容易理解和设计的目标。

但是，即使在系统复杂度削弱后，推出新的有特色的角色和编队仍然在设计和理解难度上存在挑战，这导致实际上角色在设计时就需要将其放在编队中思考，而这会导致其很难跳出编队，多个角色的自由组队也是很难实现的；同时，由于实际上是对策略的破坏，所以对于万金油角色的设计也会极为审慎，这就导致了其最突出的问题——战斗实际节奏和队伍搭配受到严格限制。

4.2 产生的问题：战斗实际节奏和队伍搭配受到严格限制

由前文的循环拆解可见，玩家对于复杂的角色设计在起初可能产生探究学习过程，但是在探究完毕后（该过程由于大量内容创作者的参与，也是极短的，甚至玩家都不必自行研究），就会产生极为固定的战斗循环，玩家的每次战斗几乎都是原样复刻，因为显然冷启动状态下电队的充能最优解是不变的，那么在队伍可以维持最优解循环时，战斗就会变为策略活力极低的纯数值比拼战斗，这会带来很大的数值膨胀隐患。

另一方面，也不能强硬的打破最优解，由于属性基础建队思路和队伍人员职业结构基本固定，并且在当前由于各自属性特色形成了物理队打小循环，自然、冰队打元素爆发，电队打充能的整体特色，一旦对某种策略或属性进行封锁都会带来大面积的攻略困难。

4.3 观点：角色抽取驱动力将相对轻战斗或重数值

由这样的战斗底层产生的问题可见，至少在当下，《终末地》的战斗系统本身玩法不足，所以在不突破战斗系统的情况下，《终末地》的角色抽取吸引力可能轻战斗或是重数值向两个方向发展，前者是主要以对角色的喜爱为驱动，那么就需要在剧情塑造、建模甚至社区生态上进行努力，同时则可以看轻战斗系统的改造难度；后者则是简单的不断膨胀逼迫角色抽取，但是水温不断上升的问题也是明显的。

4.4 可取的改进方向

  1. 通过对怪物、规则的改动增加战斗的变化性：例如由于群怪环境可能打破电队的固定循环，使得玩家需要考虑策略的灵活性，但是这也是基于当前队伍不够丰富的环境，玩家未来可能可以通过简单的更换固定编队来应对不同环境，所以需要设计更为特殊的、对各个策略都造成影响的战斗，比如 boss 转阶段、特殊攻击等带来循环的中断，在已有的阮一、聂菲斯和阿莱克琉斯都有对应的尝试；对于规则的改动方面，经典的"危机合约"便不再赘述，给玩家带来了较大的挑战和学习深度。
  2. 增加角色可跨队适应的机制性战斗方式：以前作《明日方舟》为例，干员可以通过自身技能产生击退、快速部署、领域、脱手技等多样性，这些技能的特殊性是可以跨编队进行的，当前的梨诺就是脱手治疗并且融入跨属性多种编队思路的例子，如前文所说，该思路应以干员的对策性机制为重，避免制造大量的跨队万金油。
  3. 逐渐将属性进行融合释放元素系统活力：参考《原神》，元素系统的策略深度潜力是极大的，在玩家逐渐适应当前环境后进行逐步突破，可以释放当前锁定的元素系统的活力。
